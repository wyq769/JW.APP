# 设备生产进度查询系统（雏形 M0）

面向**片材 / 板材 / 管材 / 薄膜生产设备（挤出生产线）**的制造进度查询网页：客户端只读查询、管理端更新状态。

- 技术企划书：`docs/2026-09-18-生产状态查询系统-技术企划分析.md`（需求自问自答、领域模型、状态机、选型、API 预留、里程碑）
- 雏形：`prototype/`（零依赖纯静态，双击即用）

## 如何运行

**方式一（推荐）**：直接双击 `prototype/index.html`，即可在浏览器打开（Chrome / Edge 现代版）。

**方式二（可选）**：任意静态服务器，例如：

```bash
cd prototype
npx serve .        # 或 python -m http.server（如已安装）
```

## 演示说明

- 首次打开自动注入 **5 张订单 / 8 台设备**（2026-09-20 重生成案例）：同单两台进度分化（华南塑业 012 试机中 / 013 加工中）、试机异常（中亚管业）、带现场图（宏达包装）、进货⊥加工并行 + 同单一台未开工（恒新片材）、全部完成（金源管业）。
- 管理端登录（前端模拟，正式版接后端鉴权）：主管 **王工**、操作员 **李工 / 陈工**，密码均为 `123456`。侧边栏底部显示当前账号。
- **操作人管理**（仅主管可见）：可注册（添加即注册账号，立即可登录）/ 删除操作员；有且仅有一个主管，主管账号不可删除。
- 数据保存在**本机浏览器** localStorage；管理端改状态 → 客户端刷新/重新查询即可看到变化（同浏览器跨标签页自动同步）。
- **订单-设备两级**（FR-A12）：订单信息为 **合同号 + 客户名称置顶** → 设备数量 → 设备编号（**可多个，每台独立推进**）；管理端订单列表点行看订单详情（每台一张进度卡），或直接点击设备编号芯片查看该台；客户端查任一编号直达该台进度，详情页可点"同单设备"芯片切换；新建订单"自动编号"按数量生成连续号。
- **动态精确到设备编号**（FR-A13，2026-09-20）：所有留痕（阶段/工段变更、图片上传、追加动态）文本自包含设备编号，如 `SX-PC-2026-004「塑性挤出设备」进行中，完成度 25%`，复制/转发任意一条即可说明"哪台设备发生了什么"。
- **订单动态 + 草稿保护**（FR-A14/A15，2026-09-20）：订单详情页底部合并显示**全部设备**的动态时间线（时间倒序，每条已标注编号）；设备管理页重渲染前自动暂存未保存的滑杆/备注/阶段草稿并回填，保存其他卡片不再丢失编辑。
- **工段管理**：设备管理页"工段进度"区可新增 / 删除 / 改名（✎）/ 上下移（↑↓）排序，适配不同流程的工段构成。
- **现场图片**：每个工段可上传图片（自动压缩：长边 1000px / JPEG 68%；每工段上限 12 张），图片右下角标注**上传时的完成度**；客户端缩略展示、点击放大查看。**上传即保存**：上传时会同步保存该工段当前的完成度 / 备注，无需先点保存。
- **工段三态**（2026-09-19）：工段只有 **等待材料 / 进行中 / 生产完成** 三种状态，由完成度**自动判定**（0% → 等待材料，有进度 → 进行中，100% → 生产完成），管理端拖滑杆即实时显示状态徽章；四大阶段仍为四态（未开始 / 进行中 / 异常停滞 / 已完成）。
- **并行推进**（2026-09-19）：原材料来自不同进货商，先到料先开工——「原材料进货」未完成即可开始「设备加工」，两阶段并行、进货持续到货输出给加工；并行时"当前阶段"显示更深阶段（演示：`SX-PC-2026-003`）。试机 / 发货仍按序（软警告）。
- 管理端侧边栏可一键"重置演示数据"。
- 快速体验路径：打开客户端查 `SX-BM-2026-021`（工段带演示图与进度角标）→ 进管理端在该机"塑性挤出设备"上传一张图片（先拖动完成度滑杆）→ 回客户端刷新查看新图与角标；再打开订单 `SX-BC-2026-012`，在订单详情对比同单两台（012 试机中 / 013 加工中）各自进度。
